An interactive Power BI dashboard built using the AdventureWorks Data Warehouse to analyze sales performance across salespeople, products, territories, and time. The project combines SQL Server, dimensional modeling, DAX, drill-through navigation, and executive reporting to support data-driven sales management.

The solution follows an end-to-end business intelligence workflow by connecting Power BI directly to a SQL Server data warehouse, developing a semantic model, creating reusable DAX measures, and delivering interactive dashboards for executive decision-making.

## Technologies

**SQL Server • Power BI • DAX • Power Query • Star Schema • Semantic Model**

### Enterprise Data Model

The dashboard is built using a dimensional data warehouse containing:

- FactResellerSales
- DimEmployee
- DimProduct
- DimReseller
- DimSalesTerritory
- Date Dimensions

Power BI connects directly to SQL Server to create a reusable semantic model supporting multiple reports.
